## Featured project

### 🌶️ [spice-vizcon](https://github.com/balaji4aws/spice-vizcon) — a data story you can trust
An interactive data product on 28 years of UN food data (45,000 rows, 198 countries): where the world's spices are *grown* vs. where they're *eaten*. The engineering focus is on making every number **provably trustworthy** — one pipeline owns all the maths, 61 claims are independently re-verified, and CI fails the build if anything drifts. **[▶️ Live app](https://spice-vizcon.streamlit.app)**
